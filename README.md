# Genshin Casino

Unity 6로 만드는 캐주얼 클라이언트입니다. 로비에서 **포커**와 **SurvivorsRun**(뱀파이어 서바이버즈 스타일 사이드뷰 런)으로 들어갑니다.

이 저장소는 게임플레이와 UI 스크립트입니다. 씬, 프리팹, Addressables 콘텐츠는 유니티 프로젝트에 있습니다.

## 플레이 영상

포커 베타 영상입니다. 이미지를 누르면 재생됩니다.

[![포커 베타 플레이 영상](https://img.youtube.com/vi/6RIP7LmVRBk/hqdefault.jpg)](https://www.youtube.com/watch?v=6RIP7LmVRBk)

## 포커

- 상대를 고르고 대결 연출을 본 뒤 핸드가 시작됩니다.
- 스몰 블라인드 5, 빅 블라인드 10으로 팟을 만들고, 스트리트마다 폴드, 콜, 레이즈가 이어집니다.
- 상대는 생각 시간 뒤에 행동하고, 쇼다운에서 핸드 등급과 승패를 보여 줍니다.
- 카드, 칩, 아나운서 목소리는 Addressables 주소로 재생합니다.
- 한 판의 상태(스택, 팟, 보드)는 `PokerMatchManager`가 들고, 판이 끝나면 같이 사라집니다. `GameManager`에 남겨 두지 않습니다.

## SurvivorsRun

사이드뷰로 적을 막으며 버티는 런입니다.

- 캐릭터를 고른 뒤 세션에 들어갑니다.
- 공격은 패턴으로 나눕니다. 플레이어 아이템과 몬스터 로드아웃이 같은 패턴을 씁니다. 접촉, 투사체, 오라, 펄스, 궤도, 버프가 있습니다.
- 아이템은 무기, 패시브, 액티브, 캐릭터 고유로 나누고, 수치와 설명, 데미지 프리팹 주소는 ScriptableObject에 둡니다.
- 레벨업으로 아이템을 고르고, 중첩 한도에 닿으면 후보에서 빠집니다.
- 일시정지, 골드 획득, 아이템 획득 문구, 결과 화면이 있습니다.

## 클라이언트 구조

캐릭터, 적, 맵, 아이템 데이터는 ScriptableObject로 관리하게 작업했습니다.

UI, 인게임 프리팹, 사운드, 아틀라스는 Addressables로 로드하게 작업했습니다. 로비에서 모드에 들어가기 전에 해당 라벨을 미리 불러 옵니다.

`GameManager`는 리소스, UI, 사운드, 입력만 준비하게 작업했습니다. 포커 판과 런 세션 상태는 각 모드가 갖습니다.
